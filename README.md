# phyteam

Phyteam Media - Digital Growth & Strategic PR Platform.

## Features
- **Modern Next.js 16 (Turbopack)**: App Router with React 19 & Tailwind CSS.
- **Framer Motion Animations**: Engaging, interactive UI sections and micro-interactions.
- **Firebase Firestore Integration**: Contact inquiries and "Book a Call" requests persist in real-time.
- **Dedicated Admin Desk (`/admin`)**: Real-time lead management, client profiles, inquiry review, status tracking, and call logging.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Configure environment variables in `.env.local`:
```bash
cp .env.example .env.local
```

3. Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website, and [http://localhost:3000/admin](http://localhost:3000/admin) for the Admin Desk.
